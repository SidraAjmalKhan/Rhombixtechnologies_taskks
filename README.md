# Rhombix Technologies - Task 01: Data Analysis

Welcome to my data analysis project for **Task One** at **Rhombix Technologies**. This project explores a **bike details dataset** sourced from Kaggle. The goal is to clean, analyze, and find useful patterns in bike specifications, prices, and features.

---

## 📊 Project Overview
* **Company:** Rhombix Technologies  
* **Task:** Task 1 - Data Analysis
* **Dataset Topic:** Bike Details
* **Files Included:** Python/Jupyter analysis file and the raw/cleaned dataset  

---

##  Tools & Libraries Used
* **Python**
* **Pandas** (for data cleaning and grouping)
* **Matplotlib & Seaborn** (for data charts and graphs)
* **Jupyter Notebook**

---

##  Repository Structure

├── Rhombixtechnologies_taskss/
│   └── BIKE DETAILS.csv      # The sample dataset from Kaggle
├── bike_details_analysis.ipynb            # Jupyter Notebook with full analysis & plots
└── README.md                 # Project documentation




##  How to Run the Code
1. Clone or download this repository to your computer.
2. Open your terminal or command prompt.
3. Install the required libraries if you do not have them:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
4. Open the Jupyter Notebook (`bike_details_analysis.ipynb`) and run all the cells to see the steps and graphs.
